# Camera overlay fonts

Liberation Sans **2.1.5**, Regular and Bold, is bundled for camera annotations.
It matches the Arial-compatible typeface used by the interface on Linux and
keeps video text consistent across machines without relying on installed fonts.

Upstream: <https://github.com/liberationfonts/liberation-fonts>
